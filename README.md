# YOHAKU — 余白の実験室

**役に立たない、が、おもしろい。**

音と図形を触って遊ぶ、ブラウザーの小さな実験室です。クリーム色の背景と落ち着いたグリーンを基調に、見るだけの紹介ページではなく、実際に操作できるサイトにしています。

## できること

- **ながれを描く / FLOW FIELD** — ポインターで線の流れが変化。クリックやドラッグで揺らぎが加わります。
- **波紋をひろげる / RIPPLE GARDEN** — 触れた場所から、有機的な波紋が広がります。
- **引力であそぶ / ORBIT PLAY** — ポインターが軌道の中心を引き寄せ、クリックで軌道が揺れます。

ゆらぎ・線の数・時間の速さを調整でき、3種類の配色、ランダム生成、一時停止、初期設定へのリセットを備えています。気に入った描画はPNGで保存できます。PNGには操作パネルやカーソルは含まれません。

音は初期状態でOFFです。利用者が明示的にONにした後だけ、クリック・タップ・ドラッグで音が鳴ります。音量調整にも対応します。音源ファイルやマイク入力は使用しません。

## 起動

ビルド・パッケージインストール・APIキーは不要です。リポジトリ直下で次を実行し、表示されたポートをブラウザーで開いてください。

```sh
python -m http.server 8000
```

`index.html` を直接開くこともできますが、ファイルURLでの設定保存にはブラウザー側の制限がある場合があります。

## ファイル構成

```text
index.html       ページ構造、操作パネル、日本語の説明
styles.css       レスポンシブデザイン
app.js           Canvas描画、Web Audio、操作、PNG保存
favicon.svg      アイコン
.nojekyll        静的配信用
tests/smoke.py   ブラウザーのスモークテスト
```

外部ライブラリー、CDN、外部フォント、外部画像、アクセス解析、バックエンドは使用していません。サイトの構成ファイルだけで動作します。

## 操作とアクセシビリティ

`1` / `2` / `3` で実験を切り替え、`Space` で停止・再開、`R` でランダム生成、`S` で音を切り替えられます。Canvasにフォーカスして矢印キーで移動し、`Enter` で変化を加えることもできます。入力欄やボタン本来のキーボード操作を優先します。

タッチ操作、フォーカス表示、ラベル付きの入力、操作結果の読み上げに対応しています。OSの動きを減らす設定が有効な場合は、停止状態で開始します。利用者が再生ボタンを押すと動かせます。非表示タブでは描画ループを停止し、音声コンテキストを一時停止します。

## 設定とプライバシー

実験の種類、パラメーター、配色、シードを `localStorage` の `yohaku.settings.v1` に保存します。音のON状態は保存せず、ページを開くたびにOFFから開始します。保存領域が使えない場合や保存データが壊れている場合も、実験は継続できます。サイトから外部へのデータ送信はありません。

## テスト

テスト実行時だけPythonとPlaywrightが必要です。サイト利用者には不要です。

```sh
python -m pip install playwright
python -m playwright install chromium
python tests/smoke.py
```

既存のChromiumを使う場合は `CHROMIUM_PATH` 環境変数を指定できます。

作成時にChromiumで43項目を確認しました。実験の切り替え、実描画、一時停止・再開、PNGダウンロード、音のON/OFF、キーボード・タッチ操作、設定値の検証、保存不可時の継続、320〜1440pxの表示幅を含みます。

テストはHTML/CSS/JavaScriptをブラウザーに直接読み込んで実行します。設定の読み書きはインメモリーのストレージアダプターを使用し、保存不可時の挙動はネイティブAPIで確認します。実際のHTTP配信、実機スマートフォン、OSの音声出力の聴感確認はこのテストの対象外です。

## 公開について

リポジトリ直下の `index.html` を配信する静的サイトです。ビルド工程や独自のGitHub Actionsワークフローはありません。この変更ではGitHub Pagesの公開設定自体は変更していません。
